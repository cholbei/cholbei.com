# Cholbei social media brand kit

Use the PNG files for direct uploads. Keep the SVG files as editable, lossless masters.

## Files

| File | Size | Recommended use |
|---|---:|---|
| `cholbei-profile-1080.png` | 1080 x 1080 | Universal profile photo/avatar |
| `cholbei-cover-wide-1640x624.png` | 1640 x 624 | General wide cover; Facebook and X starting asset |
| `cholbei-cover-youtube-2560x1440.png` | 2560 x 1440 | YouTube channel banner and universal 16:9 master |
| `cholbei-cover-linkedin-4200x700.png` | 4200 x 700 | LinkedIn company Page cover |

Matching SVG source files are included for every PNG.

## Brand specification

- Wordmark: `cholbei` in lowercase
- Primary dark: `#11110f`
- Acid green: `#c9ff4a`
- Violet: `#7157ff`
- Accent orange: `#ff6433`
- Primary message: “Own your website. Own your infrastructure.”

## Upload notes

- Use the square profile image everywhere; the main mark is centered for circular crops.
- Keep important cover text centered. Platforms crop banners differently by device.
- Use each platform's crop preview before publishing.
- Do not stretch a cover to a different aspect ratio. Crop from the matching SVG master when another size is required.
